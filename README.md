This is the final Firebase-ready version of the Assignment 2 Student Management System.

## Included
### Authentication
- Register
- Login
- Logout
- Forgot Password / Reset Email
- Firebase Authentication

### Students
- Create
- Read
- Update
- Delete
- Search
- Student details
- GPA
- Status
- Firestore persistence

### Reports
- Total students
- Male/Female distribution
- Major distribution
- Average GPA
- CSV export for Excel

### Settings
- Notifications
- Compact mode
- Dark mode
- Administrator profile
- Firebase account information

### Dashboard
- Live Firestore student count
- Active students
- Average GPA
- Majors
- Recent students
- Quick actions
- Connection status

## Run in VS Code
1. Extract ZIP.
2. Open the project folder in VS Code.
3. Open Terminal.
4. Run `npm install`.
5. Copy `.env.example` to `.env`.
6. Put your Firebase Web App config into `.env`.
7. Enable Email/Password Authentication and Firestore.
8. Run `npm run dev`.
9. Open the localhost URL.

See `FIREBASE_SETUP.md` for Firebase instructions.
