# Assignment 2 — Student Management System

## Introduction
The Student Management System is a web application designed to manage student information efficiently. It provides authentication, a dashboard, student CRUD operations, reports, and system settings.

## Literature Review
Existing student management systems commonly support student registration, authentication, search, dashboards, and database management. Manual records can be slow to update and difficult to search. A centralized web application improves accessibility and organization.

## Discussion
Advantages include centralized data, less paperwork, faster searching, authentication, live cloud storage, reporting, and easy CRUD management.

Limitations include dependency on internet connectivity and Firebase services. Production systems should add stronger role-based security and validation.

## Conclusion
The Student Management System provides a practical digital solution for managing student information. ReactJS provides the user interface while Firebase provides authentication and cloud database functionality. The system can be expanded into a complete school management platform.
